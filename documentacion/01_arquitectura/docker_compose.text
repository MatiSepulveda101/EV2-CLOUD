DOCKER COMPOSE
==============

Archivo principal
-----------------
docker-compose.yml

Objetivo
--------
Levantar el entorno completo con un solo comando:

  docker compose up --build

Servicios
---------
frontend:
  Aplicacion Angular servida por Nginx.
  Se construye desde frontend/Dockerfile.
  Puerto local: 4200.
  URL: http://localhost:4200

backend:
  API principal FastAPI.
  Se construye desde backend/Dockerfile.
  Puerto local: 8000.
  URL: http://localhost:8000/docs
  Crea tablas y productos demo al iniciar si las variables lo permiten.

postgres-db:
  Base PostgreSQL local compatible con RDS.
  Imagen: postgres:15-alpine.
  Puerto local: 5432.
  Guarda datos en el volumen postgres_data.

app-pagos:
  Microservicio de pagos.
  Se construye desde microservicios/app-pagos/Dockerfile.
  Puerto local: 8002.
  URL: http://localhost:8002/docs

Variables
---------
El compose trae valores por defecto de desarrollo, por eso puede iniciar sin
crear archivos extra.

Si se crea un archivo .env en la raiz, Docker Compose lo toma automaticamente.
Ese archivo se usa para sobrescribir secretos o configuraciones:

  MP_ACCESS_TOKEN
  MP_PUBLIC_KEY
  JWT_SECRET_KEY
  POSTGRES_PASSWORD

Red interna
-----------
Todos los servicios comparten:

  microservices-network

El backend llama a pagos usando:

  http://app-pagos:8002

El backend llama a PostgreSQL usando:

  postgres-db:5432

Volumen
-------
postgres_data guarda los datos locales de PostgreSQL.

Para reiniciar la base:

  docker compose down -v
  docker compose up --build

Advertencia:
  docker compose down -v borra los datos locales.
