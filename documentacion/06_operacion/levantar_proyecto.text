COMO LEVANTAR EL PROYECTO
=========================

Requisito
---------
Docker Desktop debe estar instalado y abierto.

Validar Docker
--------------
En PowerShell:

  docker --version
  docker compose version

Si esos comandos fallan, Docker no esta disponible en la terminal.


Levantar backend y base
-----------------------
Sirve para probar:
  salud,
  usuarios,
  login,
  productos,
  carrito.

Comando:

  docker compose up --build postgres-db backend

URLs:
  http://localhost:8000/docs
  http://localhost:8000/health


Levantar todo con pagos
-----------------------
Antes:
  Editar backend/.env.
  Configurar MP_ACCESS_TOKEN.
  Configurar MP_PUBLIC_KEY.

Comando:

  docker compose --profile payments up --build

URLs:
  http://localhost:8000/docs
  http://localhost:8002/docs
  http://localhost:8000/health
  http://localhost:8002/health


Detener contenedores
--------------------
  docker compose down

Detener y borrar base local
---------------------------
  docker compose down -v

Advertencia:
  down -v elimina los datos locales de PostgreSQL.


Ejecutar backend sin Docker
---------------------------
Desde EV2-CLOUD:

  cd backend
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  $env:DATABASE_URL="sqlite+pysqlite:///./dev.db"
  $env:JWT_SECRET_KEY="local-secret-key-with-enough-length"
  .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

URL:
  http://127.0.0.1:8000/docs
