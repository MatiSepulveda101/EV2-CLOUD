COMO LEVANTAR EL PROYECTO
=========================

Requisito
---------
Docker Desktop debe estar instalado y abierto.

Validar Docker
--------------
En PowerShell:

  docker --version
  docker compose version

Si esos comandos fallan, Docker no esta disponible en la terminal.


Levantar todo
-------------
Desde la raiz EV2-CLOUD:

  docker compose up --build

Servicios levantados:
  frontend
  backend
  postgres-db
  app-pagos

URLs:
  Frontend:       http://localhost:4200
  Backend docs:   http://localhost:8000/docs
  Backend health: http://localhost:8000/health
  Pagos docs:     http://localhost:8002/docs
  Pagos health:   http://localhost:8002/health


Configurar pagos reales
-----------------------
El proyecto inicia sin credenciales de MercadoPago, pero checkout real requiere
MP_ACCESS_TOKEN.

Crear .env desde la plantilla:

  Copy-Item .env.example .env

Editar .env y completar:

  MP_ACCESS_TOKEN=...
  MP_PUBLIC_KEY=...

Volver a levantar:

  docker compose up --build


Detener contenedores
--------------------
  docker compose down

Detener y borrar base local
---------------------------
  docker compose down -v

Advertencia:
  down -v elimina los datos locales de PostgreSQL.


Desarrollo local sin Docker
---------------------------
Solo usar esto si se quiere trabajar un servicio manualmente.

Backend:

  cd backend
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

Frontend:

  cd frontend
  npm install
  npm start
